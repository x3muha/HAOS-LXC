The original project code is Apache-2.0 (LICENSE). Home Assistant OS upstream code is Apache-2.0; its operating-system packages and bundled images have separate licenses. This repository contains only our tools, test fixtures and documentation. Build artifacts are local only; no HAOS binary or derived template will be uploaded to public Actions or releases by the current workflow.

Before distribution: identify exact upstream tag, retain upstream copyright, license and applicable NOTICE files, identify modified files, collect full Buildroot legal-info outputs and corresponding sources/patches as required, audit bundled container images and firmware separately, and review trademark use. Buildroot legal-info is a starting point, not proof of compliance. No official logos, endorsement or upstream support implied.
